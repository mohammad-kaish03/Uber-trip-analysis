# 🚕 Uber Trip Analysis — Machine Learning Project

This project explores Uber trip data using Python and machine learning to uncover patterns, optimize predictions, and deliver actionable insights. Built as part of a data analyst portfolio, it demonstrates end-to-end workflow from data wrangling to model deployment.

## 📊 Project Overview

- **Goal:** Analyze Uber trip data to identify key trends and build predictive models for trip demand and duration.
- **Tech Stack:** Python, pandas, scikit-learn, matplotlib, seaborn, Streamlit
- **Key Skills:** Data cleaning, feature engineering, exploratory data analysis (EDA), regression modeling, dashboard deployment

## 🧠 Machine Learning Objectives

- Predict trip duration based on time, location, and traffic indicators
- Forecast demand spikes using temporal and spatial features
- Evaluate model performance using metrics like RMSE and R²
